# Antigravity Session & Issue Tracker

**Định hướng:** VS Code & Antigravity IDE Extension giúp theo dõi, phân loại và quản lý các phiên làm việc của Google Antigravity trong VS Code.

**Tính năng chính:**
- 🤖 Theo dõi session Google Antigravity theo thời gian thực (real-time)
- 📊 Dashboard trạng thái trực quan: Running (Đang chạy), Need Accept / Question (Chờ duyệt / Câu hỏi), Done (Đã hoàn thành)
- 🔍 Phân tích chi tiết: Token In / Out, số lượt tương tác (Turns), Model AI (`Gemini 3.8 Flash`, `Gemini 3.8 Pro`)
- 🎯 Hỗ trợ song song quy trình quản lý theo Issue (`#xxxx`) và Chat tự do thông thường
- 🌿 Tự động nhận diện Git branch, Sub-projects trong workspace và Git worktrees
- ⚡ 1-Click mở phiên làm việc trực tiếp trong Antigravity IDE (`antigravity.openConversation`)
- ➕ 1-Click tạo cuộc trò chuyện mới (`antigravity.startNewConversation`)
- 📱 Tích hợp linh hoạt: Sidebar Activity Bar, File Tree Explorer, Source Control Git

**Mục tiêu:** Giúp lập trình viên làm việc hiệu quả và kiểm soát toàn diện các tác vụ song song của Google Antigravity mà không lo bị trôi lịch sử hay quên task đang chạy.

**Trạng thái:** ✅ Production-ready - Đã build và phát hành trên GitHub.
